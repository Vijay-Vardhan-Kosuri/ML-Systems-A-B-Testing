# ML A/B Testing Console

Enterprise ML Systems UI for designing, running, and analyzing A/B tests and experiments.

## Features

- Experiment lifecycle (draft → running → completed)
- Variant management and traffic allocation
- Metrics catalog and primary/secondary metrics
- Statistical significance, uplift, and sample size planning
- Feature flags and assignment strategies
- Dashboard with active experiment overview

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

Open http://localhost:3000

type this http://localhost:3001

## Build

```bash
npm run build
```

## Tests

```bash
npm test
```

## Stack

React 18, TypeScript, Vite, Tailwind CSS, Zustand, React Query, Recharts, Zod
